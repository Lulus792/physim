# Freigegebene Ergänzungen der Physim-Oberfläche

Status: **vom Nutzer am 25. Oktober 2026 ausdrücklich ausgewählt.**
Die vorherige Auswahlphase ist für die folgenden Teile abgeschlossen.
Dies ist eine Designfreigabe, keine Bestätigung einer fertigen nativen Umsetzung.

| Thema | Freigabe |
| --- | --- |
| Vollständiger Arbeitsraum ohne geladenes Projekt | Bestätigte Leeransicht |
| Protokoll | **C · Navigator** |
| Szene & Werte | **A · Werkbank** |
| Auswertung | **A · Werkbank** |
| Läufe und Serien | **A · Werkbank** |
| Neues Projekt | **B · Fokus**, geführter Dreischritt |
| Datei-Explorer | **A · Werkbank**, Liste und Vorschau |

Die Auswahl stammt aus der direkten Nutzernachricht in diesem Designchat.
Sie hebt die vorherige Übernahmesperre für genau diese ausgewählten Teile auf.
Andere Varianten bleiben Vergleichsmaterial. Keine erneute Designauswahl vorschalten.

Maßgeblich sind die [Spezifikation](../visuals/design-options/APPROVED.md),
die [gemeinsame ausgewählte Referenz](../visuals/design-options/index.html?approved=1&topic=empty)
und die in der Spezifikation zugeordneten Bilder des Vergleichsstands `5717ba7`.
Die [maschinenlesbare Auswahl](../visuals/design-options/selection.js) legt
die Darstellung jeder Kategorie und der eingebetteten Dialoge fest.

Der Projektdialog bleibt auch beim Aufruf aus Protokoll C ein Dialog B.
Der darin verwendete Datei-/Ordner-Explorer bleibt A. Globale Variantenumschaltung
darf diese ausdrücklich gemischte Auswahl nicht wieder vereinheitlichen.

Die vorhandene native Arbeit fortsetzen und die freigegebenen Inhalte mit echten
Projekt-/Lauf-/Dateidaten verbinden. Bestehende Daten-, Docking-, Resizing-,
Fehler- und Accessibility-Verträge erhalten. Der leere Start lädt kein Beispiel.
Der [Grafikexport aus ADR 010](010-analysis-graphic-export.md) bleibt verbindlich.

Abnahme: native Bild-/Interaktionsprüfungen mit der ausgewählten Referenz,
reale Dateiauswahl/Projektanlage und Fehlerfälle, bereichsübergreifender Aufruf,
kleine Fenster, große Schrift, Themes und tatsächlich verfügbare Plattformen.
Die Browserprüfung ersetzt keine native Funktions- oder Plattformabnahme.
